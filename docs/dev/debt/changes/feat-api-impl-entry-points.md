# xgameruntime

## add Functional

- [ApiImpl](../../../core/libs/xdll/xgameruntime/ApiImpl.cpp) (xgameruntime) - GDK modules reach the runtime only through `QueryApiImpl`, `InitializeApiImpl`, `InitializeApiImplEx`, `InitializeApiImplEx2` and `UninitializeApiImpl`, then call the COM-style method tables `QueryApiImpl` returns (slot 0 to 2 `IUnknown`, methods from slot 3). The argument shapes come from call sites in two bundled GDK modules. One table is served: interface `{073b7dcb-1fcf-4030-94be-e3c9eb623428}` (XAsync and XTaskQueue), whose slots 3, 5, 7, 9 to 15, 17, 19 and 22 are mapped from the methods a bundled module calls, by argument shape and call count matched against its open-source caller, and slot 29 from being called with no arguments before every other API call (taken as `XThreadAssertNotTimeSensitive`); its other slots stop and name themselves, including ones whose function the slot order suggests. Every other interface stops with its GUIDs. The handshake functions log their values and succeed, except `InitializeApiImplEx2` with a non-null fourth argument, whose layout is unknown; whether the console runtime rejects some versions is unknown. `UninitializeApiImpl` is a stub and `XErrorReport` logs its HRESULT and message
  Closes when: each interface a title uses is mapped from measured call sites, a title's own calls confirm the mapped slots, and the handshake's checks are known
